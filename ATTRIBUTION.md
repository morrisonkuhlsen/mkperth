# Attribution

Every asset file in this repository, who made it, where it comes from and under which terms.
`cargo xtask assets` fails when an asset has no row here. Code is under the repository's
licences (MIT or Apache-2.0); the rows below say when an asset is not.

Icons, charts, themes and sample projects are drawn or defined in code and are original work
covered by the code's licences; they need no row.
